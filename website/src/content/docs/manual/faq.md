title: FAQ
description: Frequently asked questions.
---

**Does Heimdall send my data anywhere?** No network data leaves your LAN. A threat-intel lookup sends the one address you look up to a public service, and only when you ask.

**Does it need a supported router?** No. Passive mode works with any router, with fewer features. See [no supported router](/equipment/no-router/).

**Can it block devices?** Only through a router adapter that supports it. See the [equipment table](/equipment/).

**Is it safe to rely on?** It is alpha software, tested on one home network. See [the limits](/security/limits/).

**Which machine should I run it on?** A Linux machine on the same LAN, ideally wired. The full tier needs about 4 GB of RAM, and the images need about 7 GB (minimal), 8 GB (intermediate) or 10 GB (full) of free disk space; the installer checks this before it starts.

**Can I run it on a Raspberry Pi?** The images are x86-64 only for now.

**How do I add my router?** See [Contribute](/contribute/).
