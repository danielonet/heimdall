:::


The dashboard has two layouts. On a narrow screen it switches automatically to a phone layout with a bottom navigation bar; on a wide screen you get the sidebar. Adding `?mobile=1` to the address forces the phone layout on any screen.

Every page works in both layouts; the phone layout shows the same data in a single column.
