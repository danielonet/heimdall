Security · network IDS

Suricata

A signature-based intrusion detector. It compares live traffic against a rule set of known-bad patterns and tells Heimdall when one matches.

Runs in: full tier Works without a router login Alert: IDS_SIGNATURE_MATCH

What it is

Suricata is a widely used open-source IDS. Heimdall runs it in a container beside the rest of the stack. Where the other detectors look for unusual behaviour, Suricata looks for known patterns: exploit attempts, malware command-and-control traffic, protocol abuse, scans.

What it sees

Packets on the interface Heimdall sniffs (set on the Settings tab). It writes each match as a line of JSON (its EVE log); Heimdall reads that file.

Phase 1 check before publishing: state exactly what traffic reaches the sniff interface on a switched home network.

What it catches

AlertSeverityMeaning
IDS_SIGNATURE_MATCHfrom the ruleA rule matched. Heimdall maps the rule’s own priority to CRIT / WARN / INFO. The alert carries the rule name and the devices involved.

How it plugs in

Suricata container→EVE JSON log→suricata_parser→IDS_SIGNATURE_MATCH→Alert store→Correlation→Dashboard · ntfy · email

A scheduled job tails the log, turns each match into an alert, and the usual pipeline takes over: de-duplication, correlation with other alerts about the same device, notification. Suricata never blocks anything itself; only you, or an auto-block rule you enabled, can.

Runs in

minimal intermediate full

Choose the full tier at install time. The container needs host networking and raw-socket capability, like Heimdall’s own sniffer.

Limits

Read this before relying on itThese are documented, not hidden.
  • The rule set is not managed by Heimdall. Heimdall ingests whatever alerts the container produces. It does not fetch, verify or tune rules.
  • Expect noise at first. The stock Emerging Threats Open set is tuned for enterprise and ISP traffic, so ordinary home traffic can trigger alerts until you add suppressions.
  • No visibility into encrypted payloads. No TLS interception is configured.
